# Venetian Language Tools

This repository is a central hub for the development, preservation, and promotion of the Venetian language (ISO 639-3: `vec`). It contains tools, resources, and datasets to standardize and support Venetian in modern digital environments.

## Project Goals

- Promote the use of **Grafia Veneta Unitaria (GVU)** as a standard orthography.
- Provide spellcheckers, keyboard layouts, and language-learning resources.
- Build open corpora and basic NLP tools for research and app integration.
- Help Venetian become supported in CLDR, iOS, Android, and major software.

## Who Is This For?

- Developers interested in language technology.
- Learners and speakers of Venetian.
- Linguists, educators, and digital humanists.
- Members of the Venetian diaspora.

## Folder Overview

- `orthography/` — Spelling rules and orthographic guides.
- `keyboard-layouts/` — Custom keyboard layouts for PC and mobile.
- `lexicon/` — Standardized vocabulary files for spellchecking and NLP.
- `language-learning/anki-decks/` — Flashcards and study aids.
- `web-dictionary/` — Online dictionary tools.
- `spellchecker/` — Hunspell or LanguageTool spellcheck configuration.
- `corpus/` — Public domain or open-licensed text corpus for Venetian.
- `nlp-tools/` — Lemmatizers, tokenizers, and basic NLP models.
- `CLDR/` — Files and proposals for locale and OS-level support.
- `speech-dataset/` — Common Voice-compatible recordings and transcripts.
- `translations/` — UI and software translations (e.g., Firefox, apps).
- `docs/` — Grammar explanations, orthography guides, and background.
