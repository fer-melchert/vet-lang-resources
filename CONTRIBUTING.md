# Contributing to Venetian Language Tools

We welcome contributions of all kinds, including:

- Adding vocabulary entries or translations.
- Recording Venetian sentences for speech datasets.
- Writing or editing grammar explanations.
- Creating Anki decks or lesson plans.
- Improving or fixing spellcheckers and tools.

To contribute, fork this repository, make your changes, and submit a pull request.

All contributions should use the **Grafia Veneta Unitaria (GVU)** standard unless otherwise noted.

Thank you for helping the Venetian language thrive!
